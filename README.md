# 📊 EDA Tool (Python)

A simple command-line tool for Exploratory Data Analysis using Python and Pandas.

## 🚀 Features
- Supports CSV, Excel, JSON, TXT files
- View top 5 rows
- Summary statistics
- Smart auto cleaning
- Handle missing values
- Remove duplicates
- View dataset info
- Save cleaned data

## 🛠️ Tech Used
- Python
- Pandas

## ▶️ How to Run
1. Download the file
2. Open terminal
3. Run:
   python eda_tool.py
